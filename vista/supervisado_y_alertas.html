// Rebalanceo en rotación simple a la izquierda
struct Node {
    int key, height;
    Node *left, *right;
};

Node* rotateLeft(Node* x) {
    Node* y = x->right;
    Node* T2 = y->left;
    // Ejecución de pivote estructural
    y->left = x;
    x->right = T2;
    x->height = max(height(x->left), height(x->right)) + 1;
    y->height = max(height(y->left), height(y->right)) + 1;
    return y;
}
A
El puntero T2 debe asignarse al subárbol izquierdo de y antes de recalcular la altura de x.
B
La secuencia de actualización garantiza el tiempo amortizado O(1) sin inconsistencias en el recorrido en orden.
C
Se omite verificar la nulidad del apuntador y->left provocando desbordamiento en memoria compartida.
